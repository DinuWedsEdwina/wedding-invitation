# Assets Folder

This folder contains the wedding invitation images.

## Required Images

1. **img1.jpg** - Main image (used as hero image and opening invitation image)
2. **img2.jpg** - Secondary image (used in the ceremony section)

## Instructions

1. Create this `assets` folder in the same directory as `wedding-invitation.html`
2. Add your wedding photos:
   - Replace `img1.jpg` with your main wedding photo
   - Replace `img2.jpg` with another wedding photo

## Image Recommendations

- Format: JPEG or PNG
- Size: At least 1000px width for good quality
- Aspect Ratio: 16:9 or square (1:1) works best
- File Size: Keep under 2MB for faster loading

## Note

The images are referenced in the HTML file as:
- Opening invitation modal image: `assets/img1.jpg`
- Hero section image: `assets/img1.jpg`
- Second image section: `assets/img2.jpg`

Make sure the image files are in this folder for the website to display correctly.
